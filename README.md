# Spotify-Soloist-Full-Package-for-Yandex-Mini-2
Полный пакет для миграции Yandex Station Mini 2 с Spotiya на Soloist. Включает Soloist, voice control для лайков и плейлистов, поиск по трекам/исполнителям/альбомам, подавление апселлов Yandex Plus, синхронизацию громкости, LED-индикацию и приглушение музыки при обращении к Алисе. Поставляется с установщиком, скриптом смены аккаунта и инструкцией.
